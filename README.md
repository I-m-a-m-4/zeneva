# ZENEVA | Industrial Retail OS v1.7.0

![Zeneva Logo](https://zeneva.space/logo.png)

## Never Lose Sale, Never Waste Stock.

Zeneva is a borderless retail operating system designed for the modern era. It unifies high-performance inventory management, multi-store POS, real-time analytics, and localized payment gateways into a single, cohesive engine.

### 🚀 Key Platforms

*   **Desktop Station (Windows/macOS)**: The heavyweight workstation optimized for high-volume retail, thermal printing, and multi-monitor setups.
*   **Active Manager (Android)**: A tactical mobile command center for inventory audits, floor sales, and real-time mobile reporting.
*   **Web Portal**: Access your business intelligence and settings from any browser, anywhere in the world.

### 🛡️ Core Capabilities

- **Zen AI Integration**: Predictive analytics that tracks "trapped cash" in inventory and suggests optimal restocking parameters.
- **Local-First Engine**: Work offline for days—sync in seconds when connectivity returns. Built for high-reliability environments.
- **Unified Global Sync**: Real-time parity between your physical store registers and your online storefront.
- **Industrial Performance**: Sub-10ms UI response times across all modules, even with 10k+ SKUs.

### 🛠️ Developer Setup (Next.js 15 + Tauri 2.0)

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/I-m-a-m-4/zeneva.git
    cd zeneva
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run Dev Environment**:
    ```bash
    npm run dev
    ```
4.  **Tauri Dev (Desktop Mode)**:
    ```bash
    npm run tauri dev
    ```
